# Gem Game 💎

Небольшая браузерная веб-игра для тестирования и демонстрации возможностей AI-ассистента в парной веб-разработке.

## 📌 О проекте
Проект представляет собой интерактивную веб-игру, разрабатываемую с нуля. В процессе создания тестируются навыки проектирования архитектуры, написания чистого кода, создания анимаций, игровой логики и оптимизации интерфейса.

## 🛠 Технологический стек
- **HTML5 / CSS3** — интерфейс, стилизация и визуальные эффекты
- **JavaScript (ES6+)** — игровая логика, управление состоянием и анимации
- **Canvas API / DOM** — отрисовка игрового поля и элементов

## 📂 Структура проекта
```text
Игра Gem/
├── .gitignore          # Исключения версионного контроля
├── README.md           # Документация проекта
├── index.html          # Главная страница игры (в разработке)
├── css/                # Стили и анимации
└── js/                 # Модули игровой логики
```

## 🚀 Запуск проекта
Так как игра является клиентской веб-игрой:
1. Клонируйте репозиторий:
   ```bash
   git clone git@github.com:ShozProg/gem-game.git
   ```
2. Откройте `index.html` в любом современном веб-браузере или запустите локальный сервер (например, через Live Server или `npx serve`).
