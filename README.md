# Gem Chess ♟️💎

Классические шахматы в браузере с поддержкой мультиплеера для двух игроков через **WebRTC (PeerJS)**, одиночной игры против **шахматного AI-бота (3 уровня сложности)** и режима игры на одном экране (**Hotseat**), развернутые на **GitHub Pages**.

🎮 **Играть онлайн:** [https://shozprog.github.io/gem-game/](https://shozprog.github.io/gem-game/)

---

## ✨ Возможности игры
- **Одиночная игра против AI-бота:**
  - 3 уровня сложности:
    - 🟢 **Лёгкий (Easy)** — подходит для новичков и свободной тренировки.
    - 🟡 **Средний (Medium)** — позиционная оценка, тактический расчет глубиной 2 полухода.
    - 🔴 **Сложный (Hard)** — алгоритм Минимакс с альфа-бета отсечением, таблицы ценности позиций фигур (PST) и расчет тактики.
  - Человечная имитация расчета с индикатором размышлений.
- **Выбор стороны при создании игры:**
  - Возможность играть за **⚪ Белых**, **⚫ Черных** или выбрать **🎲 Случайный** цвет в любом режиме.
  - Автоматический разворот доски для черных фигур.
- **Мультиплеер для двух игроков (P2P по ссылке):**
  - Подключение без стороннего сервера и регистрации через **PeerJS (WebRTC)**.
  - Создатель игры отправляет короткую ссылку другу — мгновенное прямое соединение с нулевой задержкой.
- **Локальный режим (Hotseat):**
  - Игра вдвоем за одним экраном с кнопкой переворота доски `🔄 Развернуть`.
- **Полные правила шахмат (ФИДЕ):**
  - Шах, мат, пат.
  - Рокировки (короткая и длинная).
  - Взятие на проходе (*en passant*).
  - Превращение пешки с выбором фигуры (Ферзь, Ладья, Слон, Конь).
  - Ничья при троекратном повторении позиции или недостатке материала.
- **Контроль времени (шахматные часы):**
  - Рапид (10 мин), Блиц (5 мин, 3+2), Пуля (1+1), Классика (15+10) и Без времени.
  - Автоматическое поражение при падении флажка (00:00).
- **Визуализация и UX в 2D:**
  - Векторные SVG-фигуры.
  - Перемещение как кликами, так и с помощью **Drag & Drop**.
  - Подсветка ходов, взятий, шаха королю и последнего хода.
  - Подсчет сбитых фигур и материального преимущества (`+1`, `+3` и т.д.).
  - Звуковые эффекты на **Web Audio API** (синтез звука в браузере).

## 🛠 Технологический стек
- **HTML5 & CSS3** — адаптивная верстка, модальные окна, темная тема.
- **JavaScript (ES6+)** — игровая логика, таймеры и координация UI.
- **[chess.js](https://github.com/jhlywa/chess.js)** — библиотека правил шахмат.
- **[PeerJS](https://peerjs.com/)** — P2P WebRTC для многопользовательской игры.
- **Minimax + Alpha-Beta Pruning** — шахматный движок для игры против бота.
- **Web Audio API** — звуковые эффекты без внешних файлов.
- **GitHub Pages** — хостинг статических файлов.
