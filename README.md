# Gem Chess ♟️💎

Классические шахматы в браузере с поддержкой мультиплеера для двух игроков через **WebRTC (PeerJS)** и режима игры на одном экране (**Hotseat**), развернутые на **GitHub Pages**.

🎮 **Играть онлайн:** [https://shozprog.github.io/gem-game/](https://shozprog.github.io/gem-game/)

---

## ✨ Возможности игры
- **Мультиплеер для двух игроков (P2P по ссылке):**
  - Подключение без регистрации и стороннего бэкенда через **PeerJS (WebRTC)**.
  - Создатель игры генерирует ссылку-приглашение в 1 клик и отправляет другу.
  - Мгновенная синхронизация ходов, времени и статусов партий.
- **Локальный режим (Hotseat):**
  - Игра вдвоем за одним компьютером или планшетом.
  - Возможность в любой момент развернуть доску кнопкой `🔄 Развернуть`.
- **Полные правила шахмат (ФИДЕ):**
  - Шах, мат, пат.
  - Рокировки (короткая и длинная).
  - Взятие на проходе (*en passant*).
  - Превращение пешки с интерактивным выбором фигуры (Ферзь, Ладья, Слон, Конь).
  - Ничья при троекратном повторении позиции или недостатке материала.
- **Контроль времени (шахматные часы):**
  - Стандартные форматы: Рапид (10 мин), Блиц (5 мин, 3+2), Пуля (1+1), Классика (15+10) и Без времени.
  - Добавление секунд за ход (*инкремент*).
  - Автоматическое поражение при падении флажка (00:00).
- **Визуализация и UX в 2D:**
  - Качественные векторные фигуры (SVG).
  - Поддержка перемещения как кликами по клеткам, так и перетаскиванием (**Drag & Drop**).
  - Подсветка доступных ходов, взятий, последнего сделанного хода и шаха королю.
  - Подсчет захваченных фигур и материального перевеса (`+1`, `+3` и т.д.).
  - Запись ходов в шахматной нотации с автоскроллом.
  - Синтезированные звуковые эффекты на базе **Web Audio API** (звуки деревянных ходов, взятий, шаха, рокировки и победы без внешних аудиофайлов).

## 🛠 Технологический стек
- **HTML5 & CSS3** — адаптивная верстка, модальные окна, темы оформления.
- **JavaScript (ES6+)** — логика интерфейса, таймеры и координация игры.
- **[chess.js](https://github.com/jhlywa/chess.js)** — движок валидации правил шахмат.
- **[PeerJS](https://peerjs.com/)** — прямое P2P-соединение браузеров по WebRTC DataChannels.
- **Web Audio API** — синтез звуков на стороне клиента.
- **GitHub Pages** — бесплатный статический хостинг.

## 🚀 Локальный запуск
Так как игра является полностью клиентской:
1. Склонируйте репозиторий:
   ```bash
   git clone git@github.com:ShozProg/gem-game.git
   ```
2. Откройте файл `index.html` в браузере или запустите локальный веб-сервер:
   ```bash
   npx serve .
   ```
